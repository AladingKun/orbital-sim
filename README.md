# Orbit Lab

A personal hobby project for simulating space-related physics and orbital motion.

## About

This repository is a personal project created to explore space simulation, orbital mechanics, and basic physics programming. The goal is to experiment with how objects move in space under the influence of gravity and to build a simple visual simulation over time.

This project is mainly for learning, practice, and fun.

## Goals

- Simulate basic orbital motion
- Experiment with gravity and motion
- Visualize planets, moons, satellites, or other space objects
- Improve programming and physics skills
- Build the project step by step as a hobby

## Possible Features

- 2D orbital simulation
- Gravity between objects
- Adjustable mass, speed, and position
- Orbit trails
- Solar system presets
- Rocket or satellite simulation experiments

## Project Status

This project is currently in early development and is being built as a personal hobby project.

## Notes

The simulation may not be fully scientifically accurate at first. The main purpose is to learn, experiment, and have fun with space-related programming.
